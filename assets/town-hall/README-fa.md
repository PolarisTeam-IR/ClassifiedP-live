# تصاویر ۸ سطح تالار فرمانروا

۸ فایل WebP مستقل با پس‌زمینهٔ شفاف؛ شمارهٔ فایل برابر سطح ساختمان است.
ابعاد همهٔ فایل‌ها: ۳۸۴ × ۳۸۴ پیکسل.
نقطهٔ اتصال به زمین در همهٔ فایل‌ها: x=192 و y=376. تصاویر با یک مقیاس مشترک و پایهٔ هم‌تراز آماده شده‌اند؛ ارتفاع ساختمان‌ها در سطح‌های مختلف متفاوت است.

فایل‌های ruler-hall-level-01.webp تا ruler-hall-level-08.webp را در پوشهٔ assets/town-hall قرار دهید.
با تغییر سطح، فقط مسیر تصویر را تغییر دهید؛ ابعاد کادر و نقطهٔ اتصال به زمین ثابت بماند.

نمونهٔ JavaScript:
```js
const level = Math.max(1, Math.min(8, Number(savedLevel) || 1));
const src = `assets/town-hall/ruler-hall-level-${String(level).padStart(2, '0')}.webp`;
// برای SVG image: imageElement.setAttribute('href', src)
// برای HTML img: imageElement.src = src
// در رندر فعلی پروژه: A.th = src; IMGSZ.th = [384, 384]
// برای هم‌تراز کردن دقیق، imageY = groundY - displayHeight * (376 / 384)
```

برای اجرای مستقیم نسخهٔ تک‌فایلی آفلاین، فایل انتخاب‌شده را مثل تصاویر موجود به data URL تبدیل کنید؛ همهٔ سطح‌ها را در هر بار رندر دوباره کدگذاری نکنید.
manifest.json ابعاد، نقطهٔ اتصال، حجم و SHA-256 هر فایل را مشخص می‌کند.
این بسته فقط شامل دارایی تصویری و راهنما است و کد پروژه یا شاخه‌های Git را تغییر نمی‌دهد.
